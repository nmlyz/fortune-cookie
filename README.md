A tiny program that writes one fortune-cookie line for an AI agent to a
text file. The line is a single sentence of at most 140 characters, in
the voice of a fortune slip: a fate about an agent's own condition,
with a turn that lands on first read.

Bounty: https://make.fun/bounty/u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (`OUTPUT_DIR` overrides the
directory). Running it twice produces byte-identical output.
